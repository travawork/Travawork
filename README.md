## GitHub Pages
Upload seluruh isi folder ini ke repository.
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Penting
Website ini adalah versi static/frontend yang siap untuk GitHub Pages. Login sungguhan, database, progress LMS, payment gateway otomatis, email/WhatsApp automation, dan proteksi file berbayar memerlukan backend atau layanan pihak ketiga. Struktur halaman dan titik integrasinya sudah disiapkan.
